# Materiales de TigerTag API para Spoolman

Esta carpeta incluye `materials.json`, un archivo compatible con **Spoolman**, una base de datos popular para registrar filamentos y bobinas de impresión 3D.

## ¿Qué contiene?

Es una lista seleccionada de materiales de impresión 3D del proyecto TigerTag, con definiciones normalizadas según su protocolo NFC (compatible con RFID).

## API REST pública y gratuita

También puedes obtener la lista actualizada desde la API pública:

- [Archivo JSON en vivo](https://api.tigertag.io/api:tigertag/SpoolmanDB/materials)
- [Documentación de la API (Swagger)](https://api.tigertag.io/api:tigertag)

La API es gratuita, de acceso ilimitado, anónima (no requiere iniciar sesión) y puede usarse desde cualquier sistema, aplicación o servidor.

## Importar a Spoolman

1. Descarga [materials.json desde GitHub](https://raw.githubusercontent.com/TigerTag-Project/TigerTag-RFID-Guide/main/SpoolmanDB/materials.json).
2. En Spoolman, abre la sección de materiales y busca la opción para importar.
3. Selecciona el archivo descargado.

> Nota: TigerTag no desarrolla Spoolman. Si tienes dudas sobre el proceso de importación, consulta su documentación oficial.

## Acerca de TigerTag

TigerTag es un protocolo de código abierto que integra datos NFC/RFID en flujos de impresión 3D. Más información en [tigersystem.io](https://tigersystem.io).
